# s-mini

Synthetic v2 fixture with a deterministic PRNG: 31 frames at 10 Hz in a Z-up
world, generated by `node scripts/fixtures/make-s-mini.mjs`. The same points and
poses come out on every run.

- `manifest.json` — the historical v2 manifest (see `docs/data-formats.md`).
- `INDEPENDENT_EXPECTED.json` — hand-computed ground truth for interpolation
  and projection, not produced by product code.
- `checksums.json` — content hashes for the fixture files.

This fixture contains no third-party data and is not covered by any dataset
term. It is a schema, checksum and geometry reference only: the runtime reads
format version 1, so v2 manifests are historical verification inputs and are
not accepted as live dataset inputs.
