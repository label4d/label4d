# KITTI 真实相机预览

运行 `pnpm fixtures:camera-preview`，然后打开 `/?manifest=/kitti-camera/manifest.json`，或使用「文件与导出 → KITTI 真实相机序列」。当前本地已生成 200 帧数据。

生成器读取 `fixtures/r-mini` 的 KITTI drive 0084 相机照片、同帧世界点云、自车位姿及 cam2 标定；将世界坐标从 Z-up 显式转换为 `(x,z,-y)` 的右手 Y-up，输出独立的 v1 预览序列。自车和相机传感器坐标基保持不变，世界点云和 ego→world 位姿同步转换。原始夹具不修改，原有演示文档也不被覆盖。

生成资源位于 `apps/web-ui/public/kitti-camera`，不纳入 Git；其他机器需先准备 R-mini 数据并执行生成命令。生成的预览没有导入参考框、BEV 底图或高度场，不代表完成 v2 迁移。原有 v2 运行时拒绝策略保留。

真实序列默认显示照片，点云投影按需开启；合成序列标注「合成示意图」。加载自定义序列时，缺省快照若返回 Vite HTML 回退，不再当作 JSON 导入并阻断持久化初始化。

验证包含帧 0、12、199 的点云坐标和相机像素转换一致性，以及浏览器照片解码尺寸（1242×375）、切帧、投影开关和专注模式重挂载。该验证确认转换保持现有标定投影，未完成标定的独立精度验收。
