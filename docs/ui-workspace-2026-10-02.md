# 标注工作台界面优化 · 2026-10-02

架构修复先独立提交为 `48ae868`。本轮调整工作台界面、日常操作路径和多视图呈现，保留现有编辑、撤销及持久化接口。

## 设计与操作

- 品牌标记采用坐标括号与前进三角，呼应空间标注和逐帧工作。底色 `#101820`、面板 `#17212c`、主文字 `#e5edf4`、次级文字 `#b3c2d0`、操作青色 `#70dae0`、选中工具与关键帧紫色 `#bcacfa`。字体使用 Avenir Next、Segoe UI、PingFang SC 系统回退。
- 顶栏集中序列、本地保存状态、复核与导入导出；左侧工具栏固定工具和快捷键；主视图上方提供当前工具提示和显示设置。
- 点云主视图、纵向正交三视图和相机区保持同步；相机区、属性栏、时间轴支持拖动及键盘调整。专注模式扩大主视图，小屏属性栏改为抽屉。
- 对象列表支持类别或 ID 搜索、轨迹与几何筛选、隐藏和多选；可收起列表，给属性编辑留出空间。
- 属性区分组展示位置、尺寸、旋转、关键帧、插值及其他属性；数值在失焦或 Enter 时提交，Escape 取消。当前帧编辑作用范围明确，末个关键帧受保护，多选显示批量操作。
- 帧号可直接输入；方括号始终切帧，方向键在选中对象时微调。连续切帧基于 requestedFrame，防止资源加载期间使用旧呈现帧。
- 相机按传感器比例适配区域，投影限制在图像边界；正交视图按选中对象尺寸聚焦，保持比例，并修正投影平面与相机方向、拾取的对应关系。平移和缩放在渲染循环中持续生效。
- 保存失败与操作错误在工作台内显示；快照、nuScenes 草稿与演示模型候选使用明确文案。布局偏好单独存储，不增加标注文档版本。
