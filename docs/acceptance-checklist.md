# 独立验收步骤与清单

初始状态：全部未执行。复选框仅由独立验收者实际完成后勾选；实施 AI 在自己的交付报告提供自测映射。M1 是第一条闭环，FULL 是后续全需求验收，不混用。

## 1. 验收步骤

1. **锁定交付物**：读取 DELIVERY.md，记录源码基线、差异、数据 hash、环境、实际命令与声称通过的范围。
2. **审查测试可信度**：检查独立预期是否引用产品数学函数、UI 测试是否绕过输入、测试模式是否改变业务、失败是否被 skip/重试掩盖。定点读实现与测试即可，不必先通读全部代码。
3. **运行前检查**：执行 preflight，按固定依赖安装/启动；验收使用隔离目录和浏览器 profile。确认资源和存储不来自实施者遗留的隐藏内存状态。
4. **运行领域与构建检查**：必要测试和构建通过，核验迁移、合法/非法输入以及事务/调度不变量。
5. **独立运行 J01**：S-mini 和 R-mini 分开各连续三次；每次重新创建隔离测试文档；恢复步骤内部保持该次 profile，不能重新导入替代恢复。
6. **运行 F01–F06**：独立核对故障确实触发，检查最终数据、持久化与资源结果；未触发故障的绿色测试不计通过。
7. **实际 computer use**：只拿任务目标，通过界面完整走一遍；查看视觉、可发现性、误点、焦点与取消问题。归档动作和关键截图。
8. **独立读取导出**：检查下载文件内容和已固定参考；自有格式再导入空白文档；区分草稿与正式交付门禁。
9. **执行所承诺的性能档位**：FULL 必做，M1 可未覆盖但须声明；基于固定硬件数据测量，不用合成小样本推断 3000 帧生产性能。
10. **出具结论**：逐 ID 填状态与证据，列严重度、复现方式、影响及修复后需重测项目。保留全部失败运行。

## 3. FULL 扩展清单（M1 不自动覆盖）

- [ ] FULL-01：拆分、合并、裁剪、延伸、区间变换保持范围外状态；undo/redo 与审核身份正确。
- [ ] FULL-02：静态折线/多边形、顶点编辑、无效几何、缺高度/LOD 精度和全有效期影响。
- [ ] FULL-03：针孔畸变、各已声明鱼眼模型、越界/曲线投影、重叠拾取与点云融合；独立像素参考。
- [ ] FULL-04：模型候选来源、筛选、接受/驳回、非法批次与事务撤销；大批量资源与延迟。
- [ ] FULL-05：nuScenes 明确 profile 后经目标下游读取器验证；不支持属性/几何明确报告。
- [ ] FULL-06：完整需求矩阵覆盖测量、三视图、快捷键、筛选、跨帧复制、时间轴和自车相关能力。

- [ ] FULL-10：目标标注精度有独立核验参考与容差；AI 无法确认的真实几何问题不自动通过。

## 4. 结果与严重度

每项状态使用 PASS / FAIL / BLOCKED / NEEDS_REVIEW / FLAKY。范围外项目单列，不计入通过比例；M1 必需项存在任一非 PASS，则 M1 不授予通过。资料齐全但未独立重跑只能称“交付可验收”。

- **P0**：已保存数据丢失/损坏、错帧提交、坐标系统性错误、半事务；阻止任何生产验收。
- **P1**：主流程无法完成、撤销语义错误、复核/导出门禁错误、无法恢复的资源阻塞；M1 不通过。
- **P2**：不阻断主流程的视觉、效率或次要行为问题；保留记录。若违反 M1 必需断言，该项仍是 FAIL，不能靠降严重度绕过门槛。

修复后由验收者重跑失败项、受影响范围和一次完整 J01；修改夹具/标准答案/容差需要说明正确性依据并重新建立完整基线。原有失败或 flaky 历史不能删除。

## 5. 验收报告模板

```text
验收版本 / 源码摘要 / 夹具版本 / 环境：
范围：M1 或 FULL（明确本轮子范围）
已独立执行的命令与 computer use 任务：
逐项状态表：ID | 状态 | 实际结果 | 证据路径
失败问题：严重度 | 复现步骤 | 预期/实际 | 影响 | 重测要求
缺失条件与未验证能力：
性能测量边界：
最终结论：通过 / 不通过 / 条件不足未完成
```

验收结论必须基于本次实际执行与查看的证据，不能照抄实施 AI 的完成总结。实现自测与独立验收分别保存，后续实现者可以据失败项继续修复。
