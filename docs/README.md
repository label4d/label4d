## 第一轮交付范围

以 M1“真实序列的单人标注与交付闭环”为第一轮：加载 → 画轨迹 → 插值帧修改 → 跨视图检查 → 撤销 → 保存恢复 → 复核 → 自有格式导出；配套可靠性故障测试与 computer use 检查。

M1 通过不代表全部 requirements 通过。静态几何全工具链、所有鱼眼变体、模型辅助大批量、全规模性能等在追踪矩阵单独验收；nuScenes profile 未确定前不得声称兼容。不得为缩小本轮范围删除已有功能或放宽现有数据正确性。
