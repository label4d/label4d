# 路线图

以下为尚未实现或仍需验证的工作，不是当前产品能力承诺。

| 方向 | 需要解决的问题 |
| --- | --- |
| v2 数据模型 | 完整姿态编辑/撤销/持久化/导出与兼容迁移；v1 编辑保留，规范化源浏览已有真实时间与完整姿态 |
| 复核记录 | 按对象/帧保存证据与失效范围，替代仅有的文档整体 QA |
| 资源管线 | 分离 fetch/decode/upload，加入 Worker 解码与上传节流；保留呈现一致性 |
| 规模验证 | 在明确硬件和数据规模上测帧时间、加载延迟、内存与长时间运行 |
| 数据适配与交付 | 更多同步数据集、目标导出规范及独立数值校验器 |
| 模型辅助 | 接入真实模型，建立候选审核和质量评估 |
| 协作 | 服务端文档、权限、冲突处理和多人编辑；当前仅浏览器本地保存 |

开源发布的准备工作已有进展：项目许可证确定为 MIT（见 `LICENSE`），第三方组件与 KITTI 参考数据的归属记录在 `NOTICE`，干净检出中的安装、单测与构建已验证通过。发布前仍需：在干净检出中验证真实数据加载、准备首个发布标签与发布说明，并完成公开托管地址的迁移。未经实测，不声明生产就绪或全规模性能。

Waymo Perception 的离线规范化契约与 Python 适配器已实现，见 [离线数据契约](normalized-data.md)。浏览器 DatasetProvider、真实时间与完整姿态只读展示已实现；后续完成完整姿态编辑闭环，再用 PandaSet 场景验证通用性；阶段状态见 [多数据源设计](multi-dataset-design.md)。
