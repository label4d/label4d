# 路线图

以下为尚未实现或仍需验证的工作，不是当前产品能力承诺。

| 方向 | 需要解决的问题 |
| --- | --- |
| v2 数据模型 | 显式时间戳、坐标版本、精度选择及兼容迁移；当前只接收 v1 Y-up |
| 复核记录 | 按对象/帧保存证据与失效范围，替代仅有的文档整体 QA |
| 资源管线 | 分离 fetch/decode/upload，加入 Worker 解码与上传节流；保留呈现一致性 |
| 规模验证 | 在明确硬件和数据规模上测帧时间、加载延迟、内存与长时间运行 |
| 数据适配与交付 | 更多同步数据集、目标导出规范及独立数值校验器 |
| 模型辅助 | 接入真实模型，建立候选审核和质量评估 |
| 协作 | 服务端文档、权限、冲突处理和多人编辑；当前仅浏览器本地保存 |

开源发布前还需确定项目许可证、复查第三方与参考数据归属，并在干净检出中验证安装、合成演示、构建和可选数据工具。未经实测，不声明生产就绪或全规模性能。
